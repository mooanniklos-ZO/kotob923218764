# 🌿 تطبيق كتاب «إستكفي مما تزرع» (Istakfi Mima Tazra)
### للمؤلف الدكتور مالك عبدالرحمن الرميمة

تطبيق أندرويد متكامل وتفاعلي مبني بأحدث تقنيات **Android Jetpack Compose** و **Material Design 3** لتحويل كتاب **«إستكفي مما تزرع»** إلى دليل رقمي وعملي للزراعة المنزلية، واستصلاح المساحات، وإدارة مياه الري، وتحقيق الاكتفاء الذاتي الغذائي.

---

## 📱 مميزات التطبيق الرئيسية

### 1. 📖 قارئ الكتاب ثلاثي الأبعاد (3D Interactive Book Reader)
- تصفح واقعي لجميع صفحات الكتاب الـ 15 مع مؤثرات ظل العمود الفقري (Spine Shadow) والتقليب التفاعلي.
- فهرس سريع (Table of Contents) للتنقل بين الفصول والصفحات.
- تحكم في حجم الخط (تكبير/تصغير)، والوضع ثلاثي الأبعاد، وحفظ الصفحات في المفضلة.
- قارئ صوتي رقمي ذكي (**Text-to-Speech**) باللغة العربية مع إمكانية التحكم في سرعة الصوت (0.75x, 1.0x, 1.25x, 1.5x).
- محرك بحث نصي فوري داخل جميع صفحات الكتاب.

### 2. 🌱 موسوعة المحاصيل والأشجار الشاملة (Crops Encyclopedia)
- دليل زراعي لأكثر من **45 محصولاً وشجرة** ذُكرت في فصول الكتاب (طماطم، بطاطس، بسباس، كزبرة، بقدونس، نخيل، بن يمني، عنب، مانجو، شاي، حبحب، رمان...).
- بطاقات تفصيلية توضح: طريقة وجدول الري، نوع التربة المناسبة، عمق الغرس والبذر، أسلوب الحصاد، ونصائح د. مالك الرميمة الزراعية.
- تصنيف حسب الفئات (خضروات ورقية، ثمرية، حبوب وبقوليات، نباتات عطرية وطبية، أشجار مثمرة).

### 3. 🏡 المخطط وحاسبة المساحات والري (Garden & Irrigation Planner)
- **حاسبة المساحة والتربة**: تقدير عدد الأحواض وأكياس التربة الخصبة واستهلاك المياه اليومي بناءً على المساحة المتوفرة (م²).
- **بروتوكول الري الموفر**: جداول الري المذكورة في الكتاب (يومي، كل 3 أيام، أسبوعي، الري بالتنقيط عبر الأنابيب لتوفير 70% من المياه).
- **قائمة مهام تفاعلية**: خطوات تجهيز واستصلاح الحديقة، التسوير، والسماد، والدعامات.

### 4. 📝 الملاحظات والتجارب الزراعية (Notes & Bookmarks)
- تدوين اليوميات الزراعية وملاحظات التسميد ومواعيد الغرس مع ربطها برقم صفحة الكتاب ذات الصلة.
- تبويب مخصص للوصول السريع لكافة الصفحات المحفوظة في المفضلة.

### 5. 👨‍🌾 عن المؤلف ورسالة الاكتفاء الذاتي
- بطاقة تعريفية بالمؤلف **د. مالك عبدالرحمن الرميمة** مع إمكانية الاتصال المباشر ومراسلة واتساب عبر الرقم الموثق: `771134103`.
- نص إهداء الكتاب للوالد رحمه الله، ورسالة الخاتمة الوطنية الملهمة («أمة لا تزرع كيف لها أن تحصد؟!»).

## 🛠️ البنية التقنية (Tech Stack)

- **Language:** Kotlin 2.0+
- **UI Framework:** Jetpack Compose (Material Design 3 - M3)
- **Architecture:** Clean Architecture + MVVM (Model-View-ViewModel)
- **State Management:** Kotlin StateFlow & Coroutines
- **Navigation:** Multi-tab Bottom Navigation with RTL Layout Direction Support
- **Speech Engine:** Android Native TextToSpeech Engine (Arabic Locale)
- **Testing:** Robolectric & Roborazzi Screenshot Testing

## 🚀 البناء والتشغيل عبر GitHub Actions (CI/CD)

تم ضبط مستودع المشروع بحيث يقوم تلقائياً ببناء وتوقيع ملفات **Release APK** و **Release AAB** عند كل عملية تحديث (Push / Workflow Dispatch) باستخدام مفاتيح التوقيع الآمنة (GitHub Secrets):

- `KEYSTORE_BASE64`: مفتاح التوقيع المشفر بصيغة Base64.
- `CM_KEYSTORE_PASSWORD`: كلمة مرور ملف الـ Keystore.
- `CM_KEY_ALIAS`: الاسم التعريفي لمفتاح التوقيع (Key Alias).
- `CM_KEY_PASSWORD`: كلمة مرور المفتاح الخاص.
- `GEMINI_API_KEY`: مفتاح الذكاء الاصطناعي السحابي.

### 📥 تحميل ملف الـ APK:
1. توجه إلى تبويب **Actions** في مستودعك.
2. اختر آخر عملية بناء مكتملة بنجاح (**Build & Package Android App**).
3. حمّل حزمة **`app-release-apk`** أو ابحث في قسم **Releases** لتحميل التطبيق مباشرة على هاتفك وتثبيته.
